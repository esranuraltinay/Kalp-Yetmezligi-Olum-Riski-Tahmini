# Veri

Veri dosyaları bu depoya **konmaz**. Aşağıdaki adımlarla indirin; defterlerin ilk hücresi aynı işlemi otomatik yapar.

1. Kaynak: [UCI Machine Learning Repository - Heart Failure Clinical Records](https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records)
2. İndirme: Bağlantıyı ziyaret edin, **Download** seçeneğine tıklayarak veri setini bilgisayarınıza indirin.
3. Beklenen dosya(lar): data/heart_failure_clinical_records_dataset.csv (299 hasta, 12 öznitelik ve 1 hedef sütun içerir)
4. Lisans / kullanım koşulu: Açık erişim

Hasta verisiyle çalışıyorsanız (MIMIC gibi): erişim sözleşmesi gereği veriyi hiçbir yerde paylaşmayın; yalnızca indirme talimatını yazın.
